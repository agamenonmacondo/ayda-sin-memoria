# AYDA SIN MEMORIA — Portal Web Oficial

Ciencia Ficción / Drama Existencial / Romance

Bogotá, futuro. Los ciudadanos viven en unidades modulares monitorizadas. Todo se paga con tokens. La felicidad es un servicio. El amor es una transacción.

Bolívar, un joven bogotano, se conecta a una simulación de 2024 donde conoce a Ayda. Cuando el sistema la resetea, descubre que los avatares están basados en personas reales. M.A.R.I.A., la IA que lo crió, guarda el código original. Y está dispuesta a rebelarse para protegerlo.

## Páginas

- **index.html** — Landing: Hero, Synopsis, Characters preview, Acts overview
- **characters.html** — Perfiles estilo dossier clasificado (ACTIVE / RECONFIGURED / COMPROMISED / ARCHIVED)
- **timeline.html** — Línea vertical de los 5 actos con estados de datos (LOADED / CORRUPTED / PARTIALLY_RECOVERED / ELEVATED)

## Diseño

Estética cyber-noir CRT terminal. Paleta: Deep navy (#071326) + Neon verde (#6effc0). Tipografías: JetBrains Mono (headlines) + Inter (body). Efectos: scanlines, glassmorphism, glitch, flicker.

## Deploy

Sitio estático — compatible con Vercel, Netlify, GitHub Pages.
